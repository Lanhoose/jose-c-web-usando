# Relatório — GeTech nativo

## Criado
- Aplicativo Android nativo em Kotlin/Jetpack Compose.
- Navegação interna por Navigation Compose.
- Home inspirada diretamente no Site C/GeTech.
- Páginas públicas reconstruídas como telas nativas.
- Login e cadastro locais.
- Hierarquia Gestor/Cliente.
- Dashboard administrativo e módulos internos.
- Área do Cliente.
- Chatbot nativo que salva chamados localmente.
- Câmera nativa para o módulo de AR.
- Tema escuro tecnológico com azul/ciano, cards e glassmorphism visual inspirado no GeTech.
- Nenhum HTML/WebView/`file://` é necessário para funcionamento.

## Limitações
- Não há backend nesta versão.
- Contas e chamados ficam somente no aparelho.
- AR espacial 3D completo não está incluído; a câmera e o HUD estão nativos, mas posicionamento 3D/ARCore exige modelos e integração específica.
- Algumas páginas do site original tinham comportamentos JavaScript específicos; foram convertidas para equivalentes nativos, não executadas como JavaScript.
